# Generated Deliverables

This directory contains the final user-facing files generated by the assistant.
Files here are stable — once written, they are not silently overwritten.

## File Naming Convention

### Well Spring Intervention LLC — SOP Manual

The SOP Manual is **versioned**. Each material revision is published as a new
immutable file, plus a convenience "LATEST" pointer.

| File | Purpose |
| :--- | :--- |
| `Well_Spring_Intervention_SOP_Manual_v<VERSION>[_<DESCRIPTOR>].pdf` | Immutable archive copy of a specific revision. Never overwritten. Use for audit, staff training, regulatory review. |
| `Well_Spring_Intervention_SOP_Manual_LATEST.pdf` | Convenience pointer — always a byte-for-byte copy of the most recent versioned file. Use when you just want "the current manual." |
